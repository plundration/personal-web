Oficiálna webová aplikácia pre školskú knižnicu na Gymnáziu Poštová 9 v Košiciach.

### Detaily projektu

- **Backend architecture**: Node.js REST API prepojené s MySQL databázou.
- **Deployment**: Containerizácia pomocou Docker a reverzný proxy cez Nginx.
- **Ocenenie**: Projekt získal oficiálne ocenenie Košického samosprávneho kraja (KSK).
